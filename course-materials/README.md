## 合并与解压方法

### Windows

1. 下载全部 5 个分卷文件到同一文件夹
2. 右键点击 `course-materials.zip.001` → 选择 **解压到当前文件夹**
3. 系统会自动合并所有分卷并解压

> 如果系统自带的解压工具不支持分卷，可使用 7-Zip、Bandizip 等第三方解压软件。

### macOS / Linux

```bash
# 合并分卷
cat course-materials.zip.001 course-materials.zip.002 course-materials.zip.003 course-materials.zip.004 course-materials.zip.005 > course-materials.zip

# 解压
unzip course-materials.zip
```

## 课程资料内容概览

资料共 **181 个文件**，涵盖以下主题：

- 像素画基础理论（线条、形状、明暗、色彩）
- Aseprite 软件操作与快捷键
- 着色与光线技巧
- 透视原理（一点、两点、三点、等轴测）
- 图块、图集与瓦片地图
- 游戏概念预览稿（FPS、平台跳跃、RPG）
- 等距像素画
- 游戏 UI 设计
- 动画制作（行走动画、高级动画、视差效果）
- 像素艺术工作流与变现指南

所有源文件均为 `.aseprite` / `.ase` 格式，可直接用 Aseprite 打开学习。
