## 一、Aseprite 基础操作

### 1. 常用快捷键

| 功能 | 快捷键 |
|---|---|
| 铅笔工具 | `B` |
| 橡皮擦 | `E` |
| 油漆桶填充 | `G` |
| 取色器 | `I` 或 按住 `Alt` |
| 撤销/重做 | `Ctrl+Z` / `Ctrl+Y` |
| 放大/缩小 | `Ctrl++` / `Ctrl+-` |
| 切换帧 | `,` / `.` |
| 播放动画 | `Enter` |
| 新建文件 | `Ctrl+N` |
| 导出图片 | `Ctrl+Shift+E` |

### 2. 新建画布建议

- **新手练习**：`32×32` 或 `64×64` 像素
- **角色设计**：`64×64` 或 `96×96` 像素
- **图标/道具**：`16×16` 或 `32×32` 像素

> 画布不宜过大，小尺寸更容易控制每个像素。

### 3. 常用面板

- **时间轴(Timeline)**：制作动画时使用
- **调色板(Color Palette)**：管理常用颜色
- **图层(Layers)**：分离线稿、底色、阴影、高光
- **工具栏(Toolbar)**：铅笔、橡皮、选区、油漆桶等

## 二、像素画核心知识

### 1. 线条与轮廓

- 使用 `1 像素` 线条勾勒轮廓
- 避免锯齿过多，保持线条流畅
- 初学者建议从正交视角（正面、侧面）开始

### 2. 明暗与体积

- 确定光源方向（通常左上方或正上方）
- 分为：高光、亮部、暗部、投影
- 用颜色深浅表现立体感

### 3. 抗锯齿 (Anti-aliasing)

- 在硬边缘过渡处加入中间色像素
- 不要过度使用，像素画讲究"少即是多"

### 4. 抖动 (Dithering)

- 用点状/棋盘状像素过渡两种颜色
- 适合调色板有限时营造渐变效果
- 常见模式：50% 棋盘格、垂直条纹、噪点

### 5. 调色板选择

- 新手推荐从 **限制调色板** 开始（8-16 色）
- 推荐调色板：
  - [Lospec 调色板数据库](https://lospec.com/palette-list)
  - `DB32`（DawnBringer 32色）
  - `PICO-8`
  - `ENDESGA 16`

## 三、临摹学习法

### 1. 临摹三阶段

| 阶段 | 做法 | 目标 |
|---|---|---|
| **第一阶段：描摹** | 导入参考图，降低透明度，在上面描线 | 熟悉线条和比例 |
| **第二阶段：复刻** | 看着参考图，在旁边重画 | 训练观察力和记忆力 |
| **第三阶段：改编** | 改变颜色、角度、比例或添加细节 | 形成个人风格 |

### 2. 推荐临摹顺序

1. 简单几何体（立方体、球体、圆柱体）
2. 水果、食物（苹果、面包、药水）
3. 自然物（树、石头、草）
4. 小动物（史莱姆、小鸟、猫）
5. 角色（Q版人物、NPC）
6. 场景（房间、户外小景）

### 3. 临摹要点

- 不要一开始就追求复杂作品
- 先分析参考图的颜色数量、光源、轮廓
- 画完后与原图对比，找出差距
- 记录自己的颜色调色板，便于复用
